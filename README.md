# 极速报名 · LSPosed 模块（原生接口版）

不是点屏幕，是**直接打接口**。跑在到梦空间自己的进程里，用它的登录态、它的设备指纹，毫秒级轮询。

## 一、它怎么做到的

1. **抓**：hook OkHttp，从 App 现成请求里抠 `standardUA`（设备指纹 + jPushId），从登录响应里抠 `uid` / `token`。
   → 所以**不需要你的密码**，也不用你在模块里存任何凭据。
2. **算**：自己实现 App 那套加密 —— AES-128-CBC 包体 + RSA-1024 包 session_key + `signToken = MD5((SHA512(紧凑JSON)[1::2])[0::2]).upper()`。
3. **打**：`POST https://appdmkj.5idream.net/v2/signup/submit`，提前 N 秒进窗口，每 N 毫秒一次。

因为指纹就是 App 真身发的那个，`-2000 设备指纹异常` 这个坑天然绕过去了。

## 二、装 & 跑

1. 编译（跟之前一样，压 `src.zip` 传 GitHub，配 `.github/workflows/build.yml`）；
2. LSPosed 里启用，作用域只勾**到梦空间**；
3. 强行停止到梦空间 → 重开 → **正常登录一次**，再刷一下活动列表；
   （这一步是在让模块抓指纹和 token，不登录就抓不到）
4. 回模块 App，看顶部「登录态 / 指纹」两行，四个都是"已抓"才算就绪；
5. 填活动 ID（可逗号分隔多个），提前秒数、轮询间隔、超时，点**开抢**；
6. 到梦空间可以退后台，但别让系统杀掉。

活动 ID 不知道？用旁边的 Python 脚本 `dm_auto.py list` 查，或者 App 里活动详情页链接里有。

## 三、界面上的字段

| 字段 | 说明 |
| --- | --- |
| 目标包名 | 留空即可，作用域框住了就只在这里面干活 |
| 活动 ID | 要抢的活动，多个用逗号隔开 |
| 报名开始时间 | 毫秒时间戳；填 0 就让模块自己从详情接口取 |
| 提前秒数 | 默认 15，怕服务端时间偏差就 20~30 |
| 轮询间隔 | 默认 200ms。**别低于 150**，那是给风控送人头 |
| 超时 | 多少秒还没抢到就放弃 |

顶部那块状态栏实时显示：uid / token / 设备指纹 / jPushId 抓没抓到、当前是不是在抢、上次结果。

## 四、报错对照

| 日志 | 意思 | 怎么办 |
| --- | --- | --- |
| `[11001]` | 签名错 | 加密实现被改坏了，回滚代码 |
| `[11002]` | 参数错 | 接口又收紧了，把日志发我 |
| `[-2000]` | 设备指纹不对 | 回 App 里再刷一次列表，让模块重抓 |
| `[2000011]` | 已报名 | 正常，线程自动停 |
| `[2000166]` | 还没到报名时间 | 正常，继续重试 |
| `[10005]` | token 过期 | 回 App 重新登录一次，模块会自动更新 |
| 登录态"未抓到" | 没用 App 登录过 / 作用域没勾 | 按第二节第 3 步重来 |

## 六、丑话

- 这是**接口级自动化**，不是模拟人手。平台服务协议明确禁止"非授权方式使用本服务"，判作弊最轻报名作废，重则封号 + 学校通报。**风险自担。**
- LSPosed 本身会留痕，建议：抢之前把到梦空间塞进 Magisk DenyList，抢完立刻关模块。
- 轮询别调快。200ms 已经是「人做不到但服务器能接受」的边界，再快就是刷接口。
- 加密常量来自 App 5.0.0 / 4.9.5 逆向。App 大版本一升级，RSA 公钥或签名规则一变，这套立刻全废，只能等新的逆向。
- 别拿去代抢、别倒卖名额。那是另一回事了。

## 七、目录

```
DreamHook/app/src/main/java/com/todesk/dreamhook/
├── HookMain.java        # 入口：挂 OkHttp、抓指纹/登录态、类扫描
├── DmCrypto.java        # AES + RSA + signToken + makeD（含自检向量）
├── DmClient.java        # 接口客户端（submit / detail / activities）
├── Grabber.java         # 抢票线程：等窗口 + 毫秒轮询 + 停止条件
├── Bridge.java          # 跨进程读写配置/日志（1.2s 缓存）
├── PrefsProvider.java   # 通道实现
└── MainActivity.java    # 配置界面 + 状态 + 日志
```
